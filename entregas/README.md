# Descargar AliHen

Abrir ALIHEN-seguimiento-cobros.zip en GitHub y pulsar Download raw file (icono de descarga).

El paquete contiene web/ compilada, codigo/ con las fuentes y LEER_PRIMERO.md. Conservar la aplicación original y exportar sus datos antes de usar esta versión. No abrir el nuevo index.html con file://: necesita HTTP/HTTPS.

No contiene la clave privada de OpenAI, .env.local ni los tres PDF privados aportados. La configuración de Supabase incluida es pública y está protegida mediante autenticación y RLS.
